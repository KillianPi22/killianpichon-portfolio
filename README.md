# Portfolio de Killian Pichon

[Consulter le portfolio](https://killianpichon.art)

Ce dépôt contient les pages et les ressources publiques du portfolio, ainsi que
les scripts et fichiers volontairement proposés au téléchargement sur le site.

Les outils d'édition, de génération et de test, leurs dépendances et la
documentation de maintenance sont conservés localement et exclus du dépôt.
Un clone public permet de consulter le site statique ; il ne fournit pas
l'environnement de maintenance du propriétaire.

Le site est publié par GitHub Pages depuis la racine de la branche main.
CNAME conserve le domaine personnalisé et .nojekyll le fonctionnement statique.

Un dépôt public et les fichiers servis par le site restent consultables et
téléchargeables. Le retrait des fichiers de maintenance de la version courante
ne supprime pas leurs anciennes copies dans l'historique ou les autres branches.

Les fiches Technique proposent automatiquement la dernière release stable de
[Select Similar – Angle](https://github.com/KillianPi22/c4d-select-similar-angle/releases/latest)
et de [Keyframe Reducer](https://github.com/KillianPi22/blender-keyframe-reducer/releases/latest).
Les guides sont liés à la version publiée. Le code et les notes de version sont
maintenus dans les dépôts dédiés. Les numéros et dates de version sont consultables
sur GitHub ; les fiches du site ne les reproduisent pas.
